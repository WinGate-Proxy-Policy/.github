## What Is WinGate

WinGate is a gateway helper for a network you run yourself: a home, a classroom lab, or a small office with one main connection. WinGate proxy policy is the rulebook for who may use that connection. WinGate user access is the list of those people. The helper is for guiding your own users, not for offering an open door to strangers.

WinGate web cache helps when many people open the same page, such as a course site during a lesson. WinGate bandwidth rule keeps a backup or a large study download from using the whole link. WinGate mail gateway is the mail path when this network also moves its own mail. Together they make a modest shared connection easier to live with through a normal day.

You return to WinGate proxy policy when someone new joins the house or the class. You return to WinGate web cache and WinGate bandwidth rule when the link feels busy. WinGate user access and WinGate mail gateway stay part of the same picture, so web use and mail use are not managed in two unrelated places.
